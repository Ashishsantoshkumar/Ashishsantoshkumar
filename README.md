## Featured Projects

### Trivago Automation Framework
**Stack:** `Java` · `Selenium WebDriver` · `TestNG` · `Apache POI` · `Log4j2` · `ExtentReports` · `Maven`

A data-driven, Page Object Model (POM) test automation framework automating end-to-end hotel search workflows across **Chrome, Edge, and Firefox**.

- **Dynamic UI Handling:** Implements explicit wait strategies to reliably interact with asynchronous calendar pickers and autocomplete inputs.
- **Self-Validating Pipeline:** Extracts live search results and programmatically verifies sort-order accuracy.
- **Reporting & Observability:** Generates color-coded PASS/FAIL **Excel reports** (Apache POI), interactive **ExtentReports** summaries, **Log4j2** execution logs, and automated failure screenshots.
- **CI-Ready Architecture:** Structured with Maven for automated execution inside Jenkins pipelines.

### Weather App
**Stack:** `React.js` · `Vite` · `Tailwind CSS` · `OpenWeatherMap API`

A responsive real-time weather dashboard delivering location-based forecasts with fast client-side rendering.

- **Live API Integration:** Fetches and renders real-time weather conditions from the **OpenWeatherMap API** via location-based search.
- **Performance & UX:** Bundled with **Vite** for fast load times and styled with **Tailwind CSS** for consistent responsiveness across desktop and mobile screens.
